Echo Vault
A portable and accessible file and folder encripter.
By Thundercloud


How to use.
First, install the application with the settup file, located in the same folder as this readme.
Then, as soon as you'll open it, it'll ask you for your master password. It will be used in cases if you forgot your password of a file.
Then, after entering and confirming the master password, you'll get a 64 digit recovery key, which will also be copied on your clipboard.
Warning! save this recovery key, as it is the only way you can recover your master password.
After saving the recovery key and confirming to the prompt, you're all set!

Encripting a file or a folder
Look, it's all easy.
First, click the add to vault (encript) option. After that, you'll get an option, where you can either select a file or a folder.
Then, after selecting your file or folder, you'll be asked to enter it's password.
After entering and confirming it, you'll be asked for your master password and upon entering it, the file or folder will be encripted!
Then you can close this application and enjoy, each time you'll click a file or a folder that you have encripted with echo vault, you'll be asked for the password, and it'll unlock it.
